Настоящее ТЗ устанавливает требования к конструкции, материалам, размерам и маркировке деталей и сборочных единиц, поставляемых по настоящему проекту.

### 1.3 Система обозначений

Конструкторские обозначения присваиваются по схеме: `ХХ-НННNN[-НН]`, где:
- `ХХ` — код типа документа (КД, СБ, ДЕТ и т.п.)
- `НННNN` — порядковый номер (5–6 цифр)
- `НН` — номер исполнения (при наличии)

Пример: `КД-00100`, `СБ-00200-01`

## 3. Требования к крепёжным элементам

### 3.1 Размеры болтовых соединений

Допускаются только следующие размеры метрической резьбы:
M8×1,25 / M10×1,5 / M12×1,75 / M14×2 / M16×2 / M20×2,5

Применение размеров M6, M22 и нестандартного шага резьбы — **запрещено** без согласования.

**Стандарт:** ГОСТ 24705-2004  
**Ссылка:** Раздел 3, п. 3.1

## 4. Требования к размерам и точности

### 4.1 Общие допуски

Если на чертеже не указан допуск, применяются общие допуски по ГОСТ 30893.1-2002:
- Линейные размеры до 120 мм: ±0,3 мм (класс m — средний)
- Линейные размеры 120–400 мм: ±0,5 мм

### 4.2 Толщина стенки трубы

Минимальная толщина стенки: **4,0 мм**  
Максимальная толщина стенки: **12,0 мм**

**Стандарт:** ГОСТ 8731-74  
**Ссылка:** Раздел 4, п. 4.2.1

### 4.3 Шероховатость поверхности

Шероховатость обработанных поверхностей Ra, мкм:
- Посадочные поверхности: Ra 0,8 – 1,6
- Прочие обработанные: Ra 1,6 – 3,2
- Необработанные: Ra до 6,3

**Стандарт:** ГОСТ 2789-73  
**Ссылка:** Раздел 4, п. 4.3

### 4.4 Квалитеты допусков отверстий

Допустимые квалитеты для посадочных отверстий: H7, H8, H9  
Допустимые квалитеты для валов: h6, h7, k6, n6, p6

**Стандарт:** ГОСТ 25347-2013  
**Ссылка:** Раздел 4, п. 4.4
